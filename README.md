# 🚀 Nexa Releases

This repository hosts compiled release artifacts for the **Nexa** project.

All files are published automatically by the **Build and Release Nexa** workflow in the [`Stellar-Teknoloji/Nexa`](https://github.com/Stellar-Teknoloji/Nexa) repository.

## 🔄 Release Flow

- Source repo: `Stellar-Teknoloji/Nexa`
- Workflow: `.github/workflows/release.yml`
- Trigger: push to `main` or manual `workflow_dispatch`
- Tag format: `vX.Y.Z`
- Release name format: `Nexa X.Y.Z`

## 📦 Release Assets

Each release includes:

### Windows Services
- `nexa-service-x86.zip` — Nexa Service (x86)
- `nexa-service-x64.zip` — Nexa Service (x64)

### Installer
- `nexa-installer-x86.exe` — Nexa Installer (x86)
- `nexa-installer-x64.exe` — Nexa Installer (x64)

### Database (DACPAC)
- `NexaDB.dacpac` — latest installer asset
- `NexaDB-vX.Y.Z.dacpac` — versioned DACPAC snapshot

## 📝 Notes

- Assets are generated by CI/CD; manual uploads are not required.
- If a release tag already exists, assets for that tag are updated by the workflow.
